# Formulir Harga — Srilex Buditra

Upload `index.html`, `style.css`, dan `script.js` ke repository `srilexbuditra.github.io`.

Website ini:
- menghitung estimasi harga otomatis;
- menyediakan pilihan layanan dan fitur tambahan;
- membuat pesan penawaran ke WhatsApp;
- bisa dicetak / disimpan sebagai PDF;
- responsif untuk HP dan laptop.

Harga contoh dapat diubah pada atribut `data-price` di `index.html`.
