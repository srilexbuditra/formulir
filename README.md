# Formulir Harga — Srilex Buditra

Website estimator harga untuk layanan Full Stack Developer.

## Cetak / Simpan PDF
Klik **Cetak / Simpan PDF**. Tombol tidak mewajibkan pengisian semua data.
- Laptop/PC: pilih printer **Save as PDF / Microsoft Print to PDF**.
- Android Chrome: pada dialog cetak pilih **Simpan sebagai PDF**, lalu pilih lokasi penyimpanan.

Upload `index.html`, `style.css`, dan `script.js` ke folder utama repository `srilexbuditra.github.io`.
